# ميديلين للورد — MEDELLIN Fine Floral Atelier (Jeddah)

> **"زهور تُصاغ لتبقى في الذاكرة"**  
> *A high-end luxury editorial flower boutique web experience crafted for Medellin in Jeddah, Saudi Arabia.*

---

## ✨ Features

- **Cinematic Dark Floral Hero**: 
  - Sequential word-by-word reveal (TerraElix concept).
  - GPU-accelerated cursor spotlight reveal layer (Lithos radial gradient mask).
  - Smart automatic RTL / LTR layout mirroring.
- **Complete Editorial Architecture**:
  - Occasion Discovery ("ما المناسبة؟") with 4 curated categories.
  - Signature Collections with filterable tabs (Bouquets, Vases, Grand Installations).
  - "Your Gift, Made Easy" 3-step luxury journey.
  - Interactive Bespoke Concierge Builder generating direct formatted WhatsApp orders.
  - Atelier Craftsmanship & Storytelling section.
  - Customer Reviews & Parallax Experience.
  - Jeddah Atelier location details & Google Maps integration.
- **Bilingual & Native RTL**: Complete 100% Arabic (RTL) & English (LTR) language support with instant switching.
- **Mobile-First Experience**: Optimized and tested on viewports (360px–430px) with thumb-zone floating WhatsApp CTA.
- **High Performance & Accessibility**: Fast loading, preloaded hero assets, lazy loading, and WCAG AA contrast compliance.

## 🚀 Getting Started

Simply open `index.html` in any modern web browser or serve it with any static server:

```bash
# Using npx serve or python http.server
npx serve .
# or
python -m http.server 8080
```

---

## 🧪 Testing

To run the Playwright automated QA verification across mobile, tablet, and desktop viewports:

```bash
node test_mandeline_qa.js
```
